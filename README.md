# PAL | Website QA Suite

Static, privacy-conscious marketing page for three existing published, paid Apify Actors.

- Product JSON-LD Schema Checker (50 URLs)
- H1 Heading Checker (18 URLs)
- Competitor Price & Stock Monitor (50 URLs)

No customer data, authentication, analytics, embedded third-party scripts, or direct billing are collected by this landing page. Payments and service delivery are provided by Apify; live prices should always be checked there. This repository does not distribute the private Actor source code.

For content changes, check all marketing claims against the official published Actor descriptions and latest limitations.
